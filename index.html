The Format

Simple rules. Unforgiving math.

Backyard ultra rules, run at Bear Creek Lake Park. No course record, no age-group awards — just the clock and who's still on the start line.

One wrinkle: the park closes in the evening, so this edition is capped at 11 laps — the final lap starts at 6:00 PM. If the field is still standing at that point, the race ends there rather than running the true last-one-standing format to its natural conclusion.

Each hour

A new loop starts

Everyone still in the race lines up and runs the same 4.16-mile loop. Finish early, and the rest of the hour is yours to eat, sit, or dread the next one.

Miss the gun

You're done

Fail to start the next loop on time, and your race is over. There's no partial credit — only a finish time recorded as your last completed loop.

Last one standing

Wins outright

The race only has an official finisher when exactly one runner completes a loop that no one else does. Everyone else is ranked by loops completed.

Same loop. Same hour. Again.
